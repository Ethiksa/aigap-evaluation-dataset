# PRIV-09: Synthetic Data Governance
**CreditScore AI — FinTrust Bank**

Synthetic data, generated via a validated statistical resampling technique from historical loan data, is used only for stress-testing the model's behaviour on underrepresented applicant segments (e.g., very thin-file profiles) and is never used to generate a live production score. Synthetic datasets are labelled and stored separately from production data.
