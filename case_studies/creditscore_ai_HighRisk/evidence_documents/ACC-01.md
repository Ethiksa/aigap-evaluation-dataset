# ACC-01: Accessibility Requirements Captured
**CreditScore AI — FinTrust Bank**

CreditScore AI is a staff-facing tool used via the standard FinTrust Bank loan officer desktop application, which meets WCAG 2.1 AA per the Bank's existing internal tooling accessibility standard. No applicant-facing interface exists; applicant-facing outputs (adverse decision notices) are produced in the Bank's standard accessible correspondence format, including large-print and translated versions on request.
