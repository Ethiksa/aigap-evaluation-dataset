# SEC-01: Threat Model
**CreditScore AI — FinTrust Bank**

Threats identified: unauthorised access to scores (mitigated by PRIV-05 access controls), model gaming via structured input manipulation (mitigated by SAFE-05 red-teaming), and Experian API credential compromise (mitigated by Key Vault storage and 90-day rotation, PRIV-05).

**Owner:** Digital Governance Office
