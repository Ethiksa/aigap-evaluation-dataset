# TRAN-07: AI Identity Non-Deception

**Context:** StudySpark AI is a staff-facing drafting tool. It never communicates with a student directly, so there is no scenario in which a student could ask the AI whether it is human.

**Staff-facing behaviour:** If a staff member asks the tool "are you an AI?", the interface plainly states "Yes — I'm an AI drafting assistant powered by GPT-4o." The tool is clearly labelled as an AI tool throughout the interface (see TRAN-01), leaving no ambiguity for staff users.
