# PRIV-05: Access Control and Least Privilege

**Access control:** StudySpark AI is accessible only via the university's internal Single Sign-On (SSO), restricted to the seven named LSO staff accounts. No other university staff or student accounts have access.

**Least privilege:** Staff accounts have no administrative access to the system configuration or system prompt — only Dr. Marsh and the Digital Governance Office IT lead can modify these settings.

**Credential management:** The Azure OpenAI API key is stored in the university's Azure Key Vault, accessible only to the Digital Governance Office, and rotated every 90 days.
