# TRAN-05: Logging for Accountability

**What is logged:** Each drafting session logs the requesting staff member's ID, timestamp, and a hash of the input (not the raw text) for usage volume monitoring. The raw input and generated draft are not logged or stored after the session ends.

**Purpose:** This allows Dr. Marsh to monitor usage patterns (e.g. which staff are using the tool, how often) for the monthly review process without retaining sensitive student-related content.

**Sent messages:** The final message sent to a student is logged as part of the student's standard LSO case record, as it would be regardless of whether StudySpark AI was used to help draft it.
