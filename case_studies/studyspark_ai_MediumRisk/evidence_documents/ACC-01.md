# ACC-01: Accessibility Requirements

**Current users:** 7 LSO staff, all comfortable with standard university IT systems.

**Requirements captured:**

| Requirement | Assessment | Action |
|-------------|------------|--------|
| Text readability | Standard university portal styling | Meets existing university accessibility standard (WCAG 2.1 AA) |
| Language | English only | Acceptable — all LSO staff work in English |
| Device | Desktop/laptop via university portal | No mobile access needed for this staff-only tool |
| Screen reader compatibility | Built on standard university web framework | Inherits existing accessibility compliance |

If a future staff member requires an alternative format, Dr. Marsh will coordinate with the university's staff accessibility support team.
