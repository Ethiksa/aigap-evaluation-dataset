# PRIV-03: Notice and Transparency for Data Subjects
## RecipeSuggest — Nourish Community Kitchen

**Who is affected:** Only the two kitchen volunteers who use the tool directly. No kitchen visitors or meal recipients interact with the system or have their data processed by it.

**How volunteers are informed:**
1. The tablet displays a label printed and stuck above the screen: "This tool uses OpenAI to suggest recipes. Only type ingredient names — no personal information."
2. Both volunteers were told verbally by Sam Okafor when the tool was introduced, explaining that ingredient queries are sent to OpenAI's API and that no personal data should be entered.
3. The Nourish volunteer handbook (updated June 2026) includes one paragraph on RecipeSuggest stating that it uses an external AI service and that only ingredient lists should be typed.

Because no personal data about any individual is processed, there is no requirement to notify meal recipients or kitchen visitors. The tool processes only ingredient lists typed by the volunteer.

**Owner:** Sam Okafor, Volunteer Coordinator | June 2026
