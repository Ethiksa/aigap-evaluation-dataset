# ACC-01: Accessibility Requirements
## RecipeSuggest — Nourish Community Kitchen

**Current users:** Two kitchen volunteers, both of whom are comfortable using a tablet and reading English text.

**Accessibility considerations captured:**

| Requirement | Assessment | Action |
|-------------|------------|--------|
| Text readability | Default font size on tablet may be small | Text size set to Large in tablet accessibility settings |
| Language | English only | Acceptable for current volunteers; reviewed if volunteers change |
| Physical access | Tablet placed on the kitchen counter at a comfortable height | Confirmed with both volunteers |
| Screen brightness | Kitchen lighting varies | Auto-brightness enabled on tablet |
| Cognitive load | Simple single-screen interface | Interface kept deliberately minimal — one input box, one output area |

**Disability access:** Neither current volunteer has reported a disability affecting tablet use. If a future volunteer requires an alternative format, Sam Okafor will assess options including larger text, text-to-speech, or a printed daily recipe sheet.

**Device constraint:** Single Android tablet. No mobile or desktop version needed given the two-person, single-location use case.

**Owner:** Sam Okafor, Volunteer Coordinator | June 2026
